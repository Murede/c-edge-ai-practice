## What I learned

- `sizeof` reports bytes and only yields the full array size while the expression still refers to an actual array.
- An array parameter decays to a pointer, so a function must receive its length explicitly.
- `const` communicates and enforces a read-only API contract.
- A pointer to a local automatic array becomes invalid after its function returns.
- Headers define what a module exposes; source files define how it works; `main.c` coordinates application behavior.
- Multi-file compilation requires all relevant source files and a correctly placed `-o` output option.
- Numeric type compatibility does not guarantee physical-unit correctness; ADC counts must be converted before comparison with voltage limits.
- Per-sample checking catches excursions that an average alone can hide.
